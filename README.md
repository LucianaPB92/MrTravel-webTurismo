📦 **Mr Travel Turismo**

Sitio web desarrollado como parte del proyecto integrador del curso, compuesto por páginas estáticas, estilos personalizados y funcionalidades en JavaScript para mejorar la experiencia del usuario.

🚀 Tecnologías utilizadas

🎨 HTML5 – Estructura del sitio

💅 CSS3 – Estilos, responsive design, animaciones

⚙️ JavaScript (ES6) – Lógica del proyecto

🧩 Git & GitHub – Control de versiones

📁 Asset Management – Manejo de imágenes y recursos estáticos


📄 Descripción general

Este proyecto consiste en un sitio web estático que presenta distintas secciones informativas y funcionales. Incluye navegación entre páginas, componentes visuales reutilizables, manejo de recursos, así como la aplicación de buenas prácticas de HTML semántico, CSS modular y JavaScript para interactividad básica.

🎯 Objetivos del proyecto

🎯 Practicar maquetación con HTML semántico.

🎯 Aplicar estilos avanzados usando CSS.

🎯 Implementar funciones en JavaScript para manejar dinámicas del sitio.

🎯 Organizar correctamente un proyecto web con carpetas separadas.

🎯 Mejorar la experiencia del usuario mediante componentes reutilizables.

▶️ Cómo ejecutar el proyecto

Descargá o cloná este repositorio:

git clone https://github.com/LucianaPB92/MrTravel-webTurismo.git


Abrí el archivo:

index.html


El sitio funciona sin necesidad de servidor:
✔ No requiere backend
✔ Compatible con cualquier navegador moderno
